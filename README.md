# Student Performance Analysis using SQL

A practical SQL project focused on analyzing student performance, attendance, fees, departments, cities, and admission data.

## About the Project

This project contains **51 SQL queries** designed to practice and demonstrate SQL concepts using a student dataset.

The questions start with basic data retrieval and gradually move toward more advanced analytical queries involving aggregations, subqueries, CASE statements, CTEs, and window functions.

The main objective of this project is to improve SQL problem-solving skills and understand how SQL can be used to answer practical data analysis questions.

## Dataset Analysis

The project works with student information such as:

* Student Name
* Department
* Marks
* Attendance
* Age
* Gender
* City
* Fees Paid
* Admission Date
